# محاضرات النحو والصرف — الدكتور عبد المنعم

المستودع الخاص بالموقع العام لمحاضرات النحو والصرف. مبني على النسخة السادسة من التصميم.

## المحتوى

- `index.html`: الواجهة العامة فقط، بدون بيانات الطلاب أو المدفوعات أو تسجيل دخول الإدارة.
- `.github/workflows/deploy.yml`: نشر آلي إلى GitHub Pages عند تحديث الفرع `main`، بعد تفعيل مصدر GitHub Actions من إعدادات Pages.

## هام قبل الإعلان عن الرابط

الجدول المنشور حاليًا نموذج مبدئي للمعاينة، وليس مواعيد معتمدة. يلزم تعديل مواعيد الدورة من لوحة الإدارة المحلية، ثم تصدير `index.html` جديد واستبداله في هذا المستودع، أو الانتقال لاحقًا إلى قاعدة بيانات مع لوحة إدارة آمنة.

**لا ترفع ملف لوحة الإدارة المحلية أو النسخ الاحتياطية JSON أو أسماء الطلاب أو المدفوعات إلى مستودع عام.**

## إعداد GitHub Pages

1. أنشئ مستودعًا عامًا مستقلًا.
2. ارفع هذه الملفات مع الحفاظ على المجلد `.github/workflows/`.
3. من `Settings → Pages`، حدد `GitHub Actions` مصدرًا للنشر.
4. بعد نجاح عملية النشر في Actions، افتح الرابط المعروض في Deployments.
