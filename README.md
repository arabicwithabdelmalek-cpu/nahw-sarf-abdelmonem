# موقع محاضرات النحو والصرف — الدكتور عبد المنعم

## الهيكل

- `main`: موقع GitHub Pages القديم دون تغيير.
- `development`: النسخة الجديدة التي تتصل بقاعدة Supabase مستقلة.
- `site/`: واجهة الطلاب ولوحة الإدارة، وتُنشر من هذا المجلد.
- `site/admin/`: لا تعرض بيانات خاصة إلا بعد دخول حساب موجود ضمن `public.site_admins` وبفضل صلاحيات RLS.
- `supabase/migrations/`: بنية قاعدة البيانات، والصلاحيات.

## الاستضافة الحالية

- معاينة مستقلة على Vercel: https://nahw-sarf-abdelmonem-preview.vercel.app/
- لوحة الإدارة: https://nahw-sarf-abdelmonem-preview.vercel.app/admin/

تُرفع نسخ Vercel من الملفات يدويًا في هذه المرحلة. لا يوجد ربط تلقائي بمستودع GitHub بعد؛ لا تدّعي التزامن التلقائي قبل استكمال اتصال GitHub في Vercel.

## تفعيل حساب المسؤول لأول مرة

1. من صفحة `/admin/` أدخل البريد وكلمة مرور قوية ثم اختر «إنشاء حساب للمسؤول أول مرة».
2. أكّد البريد من رسالة Supabase. إذا فتح رابط التأكيد صفحة `localhost` غير متاحة، ارجع إلى صفحة `/admin/` بعد التأكيد؛ تحقق من إعداد `Authentication → URL Configuration` في لوحة Supabase واضبط Site URL ليشير إلى عنوان الموقع الجديد.
3. يسجل المستخدم الدخول بكلمة المرور، **لكن لا يحصل على صلاحية الإدارة تلقائيًا**.
4. من لوحة Supabase وبوسيلة موثوقة، أضف حسابًا مؤكّد البريد فقط إلى `site_admins` باستخدام استعلام يعتمد على البريد المؤكد، لا ترقِّ مستخدمًا مجهولًا ولا تشارك كلمات المرور.
5. سجل الخروج ثم الدخول وراجع ظهور الدورات. يمكنك حينها تحديد بداية الدورة وإنشاء ٨ محاضرات غير منشورة تلقائيًا على السبت والأربعاء، ثم اختيار مادتها وتوقيتها ونشرها.

## الخصوصية

المفتاح الموجود في `site/config.js` من نوع **publishable** فقط، وهو مناسب للمتصفح. لا ترفع أي `service_role` أو مفاتيح سرية أو قاعدة بيانات إلى GitHub. المستودع ما زال عامًا حتى تأكيد تشغيل الاستضافة البديلة واستمرار التحديثات. صفحة الإدارة المرئية ليست في ذاتها وسيلة أمنية؛ حماية البيانات قائمة على Supabase Auth وRLS.

## المواعيد

لا نعرض تواريخ افتراضية على النسخة المتصلة. ستظهر البيانات عند نشرها من لوحة الإدارة. لم يتم اعتماد مواعيد فعلية من المستخدم حتى الآن.
